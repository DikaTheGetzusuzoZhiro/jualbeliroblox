# TAMA STORE — Modern Static Store

Website statis modern untuk TAMA STORE.

## Struktur
- `index.html` — halaman utama
- `order.html` — checkout / pembayaran
- `confirmation.html` — upload bukti & konfirmasi WhatsApp
- `style.css` — seluruh styling
- `script.js` — menu, copy nomor, QRIS, upload preview, WhatsApp
- `assets/banner.png` — banner dari chat
- `assets/product.png` — gambar produk dari chat
- `assets/qris.jpg` — QRIS dari chat

## Jalankan
Buka `index.html`.

## Deploy
Bisa langsung di-upload sebagai static site ke Vercel, Netlify, GitHub Pages, atau hosting biasa.

## Catatan
Halaman ini tidak mengirim file bukti transfer ke server. Tombol WhatsApp membuka chat dan pengguna tetap perlu melampirkan file bukti secara manual.

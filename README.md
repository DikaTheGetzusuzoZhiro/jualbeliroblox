# TAMA STORE — Website Jual Akun Roblox

Website statis siap deploy ke Vercel, Netlify, GitHub Pages, atau hosting biasa.

## Isi
- `index.html` — halaman utama + banner + produk
- `order.html` — halaman order yang terbuka di tab baru
- `style.css` — desain responsif
- `script.js` — tombol salin nomor dan tampil/sembunyikan QRIS
- `assets/banner.png` — banner yang diberikan
- `assets/produk.png` — gambar produk yang diberikan
- `assets/qris.jpg` — QRIS yang diberikan

## Menjalankan
Cukup buka `index.html` di browser.

## Deploy Vercel
Upload folder ini ke GitHub lalu import repository tersebut di Vercel. Tidak membutuhkan build command.

## Catatan
Nomor pembayaran dan gambar QRIS di website mengikuti data yang diberikan pemilik toko. Pastikan data pembayaran sudah benar sebelum dipublikasikan.
